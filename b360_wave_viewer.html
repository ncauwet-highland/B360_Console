B360 Waveform Viewer

Input. Drop one or more CSV files anywhere on this page, use Open CSV…, or paste a raw WR reply into the box at the bottom of the side panel — pasted data is named by the field under the box, or pasted-1, pasted-2… if that is left blank. Columns are time,voltage,comparator; a header row is optional and the comparator column may be absent.

Titling and colour. The plot title box in the toolbar is drawn above the plot, and it also names the file that Save PNG writes. Every trace has a colour swatch in the side panel — click it to pick any colour; the waveform, its comparator trace and its statistics block all follow.

Save PNG. The export is not a screenshot — the plot is redrawn at a fixed size with a statistics table underneath it, so the image answers on its own the questions a reader of a report will ask. The table carries one column per visible trace (its colour swatch and name doubling as the legend), every figure from the side panel, and the capture metadata from the CSV header: board, source, monitor mux and captured. Under it go the exact time and voltage window shown, any marker readings, the export time, and the divider caveat below. Rows that have nothing to say are left out.

Running inside B360_console.exe this opens a save dialog, starting in Documents\B360 captures\saved_PNGs and thereafter wherever you last saved one. The file is named after the plot title, or B360_waveform_<timestamp>.png if the title is blank. Opened as a plain file in a browser there is no dialog to offer — the image goes to the browser's download folder under the same name.

Mouse.

  • wheel — zoom the time axis about the pointer
  • shift+wheel — zoom the voltage axis  ·  ctrl+wheel — zoom both
  • drag — pan  ·  shift+drag — box zoom
  • click — drop marker A, then B (Δt and 1/Δt appear in the side panel)
  • lanes — all comparators share one lane and are told apart by colour, so the voltage plot keeps its full height however many files are open; traces at the same level are offset a couple of pixels so none is hidden
  • double-click — zoom to fit all visible traces

Reading the numbers. Time is seconds since the WG that started the capture, so the first sample is always 0. Voltage is measured at the ADC pin — the 1k/4.53k divider ahead of it is not undone, so a monitor-mux swing of 4 V arrives as about 3.277 V. The comparator column is the level latched with that same sample, for whichever channel MO had selected. Comparator frequency in the statistics panel is derived from rising edges only, which makes it directly comparable with what <ch>P reports.

Phase align. t=0 is whenever WG fired, so two captures of the same signal start at different points in the cycle and will not overlay. Ticking phase align shifts each trace onto the first visible trace's first cycle, which is what you want when checking that a waveform has not changed. It only moves the displayed time axis — the statistics that matter (sample rate, Vpp, comparator frequency) are unaffected, saved CSV still carries the real time-since-GO, and the shift applied to each trace is listed in its statistics block.

The first cycle is found as first rising edge to second rising edge of the plotted waveform, which is a cycle whatever the shape — sine, square, pulse train. The edge is timed at the 50% level of that first cycle's own swing and interpolated between samples, so it does not depend on amplitude or DC level. Nothing is averaged over the record: a mean taken across a capture belongs to no particular cycle in it, and for a machine that changes speed while the capture runs it is actively misleading. Every sample is used, sample 0 included. The measured period appears as first cycle in the statistics; on a machine that is changing speed it is the figure that differs from the whole-record comparator frequency above it.

Grid and ticks. Each labelled division is subdivided — into fifths, or quarters where the step starts with a 2 — so every minor line still lands on a round number. Tick marks are drawn on all four edges of the plot box, long for a labelled division and short for a minor one, because the grid alone washes out under a dense trace and is not what a printed plot gets measured against.

Honest rendering. When a capture is zoomed out far enough that one screen pixel spans several samples, the trace is drawn as the min/max envelope of each pixel column rather than a subsample, so narrow features are never silently dropped. Zoom in past about 4 pixels per sample and individual samples are marked.
